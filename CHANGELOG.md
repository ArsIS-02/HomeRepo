# Изменения

## 2.4.0 — не выпущено
- Журнал действий уходит в Graylog по GELF (секция `[graylog]` в homerepo.conf): поля `hr_*`, уровень warning у неудачных входов, переподписи и удаления пакетов, токенов, пользователей, подключения устройств и доступа Ansible. Пишут панель, исполнитель и командная строка (подписыватель остаётся без сети); отправка в фоне, журнал в базе остаётся полным.
- Сканер сети сообщает в Graylog о новых устройствах (`hr_event=device_new`): адрес, MAC, производитель, имя, порты, тип системы. Первое сканирование подсети событий не создаёт.
- Выгрузка инвентаря для Lookup Tables Graylog: `/api/export/inventory.csv` по токену `export_token`, ключ по адресу или по имени, `header=0` для адаптера «DSV File from HTTP».
- Раздел «Журнал»: состояние отправки в Graylog и тестовое сообщение (для администратора).
- Сторож связи с агентами: устройство молчит дольше суток — предупреждение в Graylog (`hr_event=agent_silent`, уровень warning), возвращение на связь — `hr_event=agent_recovered`; пока молчит, напоминание не чаще раза в сутки. Работает фоновым потоком панели, ручная проверка — `homerepo watchdog`.

## 2.3.0
- Раздел «Плейбуки»: конструктор плейбуков Ansible из готовых блоков (пакеты и пакеты из HomeRepo, подключение HomeRepo, обновление системы, службы, файлы, строки в конфигах, пользователи и SSH-ключи, безопасный SSH, firewalld, SELinux, пересылка журналов, ввод в домен FreeIPA, перезагрузка, команда, произвольная задача YAML), 11 рецептов, живой YAML, импорт своих плейбуков.
- Служба-исполнитель homerepo-runner: запуск ansible-playbook из очереди, проверка без изменений (--check --diff), проверка синтаксиса, остановка; события выполнения по шагам и хостам передаются в панель в реальном времени.
- Экран выполнения: сетка «шаги × хосты», подробности по каждой клетке (сообщение, diff, вывод), итог, полный вывод Ansible, повтор запуска. Упавшие запуски — в центре ошибок, все запуски — в журнале.
- Хосты для Ansible берутся из HomeRepo (группы по ОС и архитектуре); динамический инвентарь для командной строки: homerepo-inventory, homerepo inventory --ini.
- Доступ Ansible выдаёт агент: пользователь homerepo-ansible с ключом исполнителя и sudo, отзыв одной кнопкой.
- Секретные переменные запусков спрашиваются при запуске и нигде не сохраняются; задачи с ними выполняются с no_log.
- Агент 1.3: доступные обновления системы с пометкой обновлений безопасности и признаком «нужна перезагрузка»; назначение «Обновить систему» (всё или только безопасность, перезагрузка при необходимости) из карточки устройства и раздела «Назначения».
- Установщик: служба homerepo-runner, установка Ansible (--no-ansible — без него), отключение старой веб-панели Ansible (repo-panel) с импортом её плейбуков.

## 2.2.2
- Журнал действий человеческим языком: вместо JSON — фразы вроде «Установить или обновить btop на srv-files и pi-garage — при следующем опросе агента». Старые записи тоже показываются по-новому, исходная запись видна во всплывающей подсказке. Поиск работает и по этим фразам.
- Повторное открытие одного и того же отчёта (печать, скачивание) в течение 10 минут больше не плодит записи в журнале.

## 2.2.1
- Значок приложения (щит с пакетом) во всех размерах, favicon.ico, apple-touch-icon, maskable-значки и манифест веб-приложения: панель можно закрепить в Dock, на рабочем столе или на экране телефона.

## 2.2.0
- Карточка устройства: пакеты одним прокручиваемым списком по вкладкам, с поиском; нажатие на пакет открывает его карточку с действиями «Скачать в HomeRepo» (с выбором ветки), «Перевести на HomeRepo», «Обновить», «Держать версию», «Удалить с хоста» и отменой ждущего назначения.
- Забор пакета с устройства в HomeRepo работает и тогда, когда сторонний репозиторий уже не хранит установленную версию: берётся последняя версия из того же источника. Ход и итог (вплоть до публикации службой подписи) видны в назначении; для пакетов, поставленных вручную из файла, панель сразу предлагает загрузить .rpm.
- Центр ошибок: значок в шапке, окно со списком ошибок заданий, назначений и служб, подсказки «что сделать», повтор и скрытие после просмотра, отчёт об ошибках (HTML / PDF).
- Отчёты по устройству и сводный отчёт (HTML, печать в PDF).
- Установщик: создание нового ключа подписи (`--key-name`) и импорт готового (`--import-key`) для установки с нуля.
- Агент 1.2: доверяет и системному хранилищу сертификатов; новый алгоритм забора пакетов.

## 2.1.0
- Тип системы найденных устройств: точнее (приоритет — приветствие SSH и данные агента), ручное указание, нейтральные значки типов.
- Светлая и тёмная тема; сканер сети без root и без nmap; установка агента по SSH.
- Метрики и сведения о железе в карточке хоста, графики за сутки.
- Ввод текста в полях поиска и диалогах больше не сбивается.

## 2.0.0
- Первый выпуск: служба подписи отдельно от панели, панель без sudo и без доступа к ключу, менеджер устройств с агентом, назначения, журнал, установщик с переездом со старой PHP-панели и откатом.
