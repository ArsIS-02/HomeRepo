# Тесты

## Модульные (без rpm и dnf)

```bash
PYTHONPATH=lib python3 -m unittest discover -s tests -p 'test_*.py' -v
```

Проверяют сравнение версий (сверено с `rpm.labelCompare`), пароли, определение типа системы, журнал человеческим языком и сборку YAML конструктором плейбуков. Запускаются в CI.

## Сквозные (нужна система с dnf)

Проверяют весь путь на настоящей системе:

- загрузка, подпись, публикация, переподпись, перемещение;
- установка через `dnf` с `gpgcheck=1`;
- отчёт агента и классификация пакетов;
- назначения (обновление, удаление, установка, ночное окно);
- забор пакета «извне» и перевод на HomeRepo;
- плейбуки: конструктор, проверка и выполнение через исполнитель, события по шагам, остановка, секреты, центр ошибок, доступ Ansible через агента, обновления ОС.

Подготовка, на тестовой машине или в контейнере Rocky/РЕД ОС:

1. Установите HomeRepo (`deploy/install.sh`) или запустите службы вручную с тестовым `HOMEREPO_CONF`.
2. Соберите тестовые RPM (например, через [nfpm](https://github.com/goreleaser/nfpm)): `hr-hello` 1.0/1.1/1.2 (x86_64, 1.1 ещё и aarch64), `hr-common` 2.0 (noarch, подписан посторонним ключом), `hr-app` 3.0 (зависит от `hr-common`), `hr-extpkg` 0.9 (в отдельном репозитории `ext`, установлен на хосте).
3. Раздайте каталог с этими RPM по HTTP на порту 8099 (`python3 -m http.server 8099`) — для проверки скачивания по ссылке.

Запуск:

```bash
python3 tests/e2e_backend.py <временный пароль admin> <каталог с RPM>
python3 tests/e2e_agent.py   <каталог с RPM> "<команда запуска агента на тестовом хосте>"
python3 tests/e2e_ansible.py "<команда запуска агента на тестовом хосте>"
```

Для `e2e_ansible.py` на тестовой машине должны работать служба `homerepo-runner` и Ansible. Хост с адресом 127.0.0.1 выполняется локально, без SSH.

`tests/stub-createrepo_c` — упрощённая замена `createrepo_c`. Нужна только для стенда, где настоящего пакета нет; на серверах используется настоящий `createrepo_c`.
